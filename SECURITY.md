# Security policy

Report vulnerabilities privately through GitHub:
https://github.com/augustoflorentino/bitspan/security/advisories/new

Please do not open a public issue. You will get an answer within 14 days. Fixed vulnerabilities
are listed in [CHANGELOG.md](CHANGELOG.md).

Supported versions: the latest release of each major version from 1 on, for 6 months after
the next major version comes out.
